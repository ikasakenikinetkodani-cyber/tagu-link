# Tagu-Link ホームページ（YouTubeライブ配信事業版）

メイン事業を、コンサート・発表会・地域イベント等のYouTubeライブ配信としてPRする版です。
活動エリアは岡山県西部の5市町（笠岡市・井原市・浅口市・里庄町・矢掛町）です。

## GitHubでの更新
1. `tagu-link` リポジトリを開く
2. `index.html` を開き、鉛筆マークで編集
3. 既存HTMLをすべて置き換えてこの `index.html` の内容を貼り付ける
   または、既存ファイルを削除してから新しい `index.html` をアップロードする
4. `Commit changes` で保存

## 公開前に確定・追記すること
- 問い合わせ用メールアドレス・電話番号
- 対応可能な配信規模、カメラ台数、音声収録、配信時間
- 料金体系・交通費・キャンセル条件
- 配信実績やサンプル動画（許可を得たもの）
- 主催者・出演者・会場の撮影配信許諾
- 音楽著作権・原盤権・映像利用権等の確認と役割分担
- YouTubeアカウント・配信設定・アーカイブ公開方針

現時点では、実際の機材・実績・料金は未確認のため、確約表現は避けています。


## 協賛募集ページ・申込書
- `support.html` に年間協賛・イベント協賛の金額と紹介内容を追加しました。
- `sponsor.html` は協賛募集案内と協賛申込書です。ブラウザで開き「印刷・PDF保存」から印刷またはPDF化できます。
- 金額・特典は団体内で最終決定後に正式運用してください。連絡先・支払方法は未確定のため空欄・個別案内としています。


## 写真を使ったデザインについて
トップページ・協賛ページ・協賛募集案内に、イベントやライブ配信のイメージ写真を配置しています。現在は活動実績写真が未提供のため、イメージ写真を使用しています。実際のイベント写真を撮影・掲載できるようになったら、主催者・出演者等の許可を得た写真に差し替えると、より信頼感のあるサイトになります。写真は外部画像サービスから読み込むため、表示にはインターネット接続が必要です。
